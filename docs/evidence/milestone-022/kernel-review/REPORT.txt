Non-blocking runner robustness finding

A missing required file after a failed build could abort finalization, leaving RUNNING/unsealed summary files while raw logs remain retained. This was reported to the owner after launch. The concern did not trigger: this run completed, restored both images, wrote errors.json=[] and sealed all receipts. It does not invalidate this successful run. A future runner should guard its failure-sealing path.
